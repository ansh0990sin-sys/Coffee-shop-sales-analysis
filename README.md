☕ Coffee Shop Sales Analysis

A beginner-friendly Data Analysis project using Python, NumPy, and Pandas to analyze coffee shop sales data and generate a simple sales report.

📌 Project Overview

This project analyzes the sales performance of different coffee products based on:

Number of cups sold
Price per cup
Revenue generated

The project demonstrates basic data analysis techniques using NumPy and Pandas, including creating arrays, building a DataFrame, adding calculated columns, and performing statistical analysis.

🎯 Objectives
Create and work with NumPy arrays
Create a Pandas DataFrame
Calculate revenue for each coffee
Find the most sold coffee
Find the most expensive coffee
Calculate the average coffee price
Calculate total revenue
Generate a simple and readable sales report
🛠️ Technologies Used
Python
NumPy
Pandas
Jupyter Notebook / VS Code
📊 Dataset

The project uses the following sample data:

Coffee	Cups Sold	Price (₹)
Espresso	120	120
Latte	95	180
Cappuccino	150	160
Mocha	80	200
Cold Coffee	110	150
